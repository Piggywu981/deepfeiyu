# Deep肥鱼 使用说明

这份文档面向**日常使用**：怎么启动、每个页面干什么、心情怎么调、出问题先看哪里。
安装细节、全部配置项、API 与开发调试在 [README](../README.md)；插件规格与设计在 [docs/superpowers/specs](superpowers/specs/)。

这份文档也是控制台左侧「说明」页的内容：改完保存，控制台刷新就能看到，不用重启。用户可见的改动要同时更新这里和 [CHANGELOG](../CHANGELOG.md)；新增控制台页面时，下面的页面表必须补一行（有测试会检查）。

## 1. 三分钟上手

1. 双击项目根目录的 `run.bat`。首次运行会下载便携 Python 3.12（约 14MB，带 SHA256 校验）到项目内 `.python/`，建 `.venv` 装核心依赖，再拉上游素材子模块，最后打开控制台（默认 <http://127.0.0.1:8765>）。微信 4.x / 朋友圈 / 桌宠各是独立一组可选依赖，某组装不上只会关掉那个功能并打印一行说明，不影响启动；本机没有 Git 时子模块那步会跳过，桌宠与余额挂件会在页面上写明缺什么。已有 `.venv` 但不是 Python 3.12 时需要手工删掉该目录重跑。
2. 「设置 → 模型」选一档，填 API Key，点「测试连接」。
3. 「设置 → 账号与通道」确认账号的驱动与通道：
   - 微信 3.9.x：`wcferry`，填 Hook 端口；
   - 微信 4.x：`weixin4`，装好读取依赖；
   - 协议/自建网关：`webhook`，填回调地址与 Token。
4. 回到「概览」，通道显示已连接即可。私聊会按策略自动回复；群聊默认只有 `@昵称` 才回。
5. 想主动下指令，去「智能体」页；想调节情绪，去「心情」页；想让 AI 自己隔一会儿开口，去「搭话」页（默认关）。

> 控制台若设了访问令牌（`server.access_token`），首次打开会弹框要你输入；令牌只存在浏览器本地。

## 3. 日常：让 AI 接管微信

### 3.1 什么时候会回，什么时候不回

- 私聊：默认直接回。
- 群聊：默认只回 `@昵称`（昵称按账号配置）；连续对话窗口内你接过话，群里没 `@` 也可能续答。
- 拍一拍：被拍可以回一句，群里只接拍自己的。
- 以下任一情况会静默：
  - 「设置 → 自动回复策略」总开关关闭；
  - 会话被关掉 AI，或处于人工接管暂停；
  - 命中黑名单、不在白名单（若开启 only_whitelist）；
  - 不在工作时段；
  - 触发同会话最短间隔、每日上限或发送节流；
  - 模型未配置或调用失败。

会话页副标题会显示拦截原因（例如「AI 判断：群聊未 @ 我」），比只看日志快。

### 3.2 人工接管

你在某个会话里亲自回一句后，AI 默认退让一段时间（`auto.takeover_pause_min`）。会话列表里的「接管中」可以点掉，立刻恢复 AI 自动回复。

### 3.3 发送节奏

AI 发消息默认有节流：全局间隔、同会话冷却、连续对话短冷却，避免机器味。控制台人工发送不排队。被风控踢过之后，建议把节流区间整体调大养几天。

## 4. 智能体页怎么用

- 直接在输入框说人话，例如「看看张三最近在聊什么」「给李四发一句我晚点到」「把这段聊天记录总结一下」。
- 顶部可以切模型、思考强度和历史对话；生成中可以点停止。
- 智能体的工具默认只在控制台可用；自动回复要用外部工具，需要在「能力」页同时打开总开关和条目自己的 `auto_reply`。
- 余额查询只对 DeepSeek 有效；其他服务商仍会按本地牌价估算每轮成本。

## 5. 心情

心情让 AI 有一个**会自己判断、你看得见**的底色：每次成功回复后判断一次涨跌，时间线留痕，必要时把「这会儿的底子」带进下一轮提示词。

### 5.1 开启

「心情」页右上角勾选「启用心情」。默认是**关闭**的：关着不调用模型、不注入、不写心情事件。

- 设置是**按账号**存的；切账号后页面会自动重载当前账号的设置。
- 开启后不需要重启，下一轮回复就生效。

### 5.2 右下角挂饰

- 位置：控制台右下角、小鲸鱼上方。
- 按住形象图可拖动，松手后位置会记住；换浏览器或清本地存储会回默认位置。
- 点一下形象图开关面板；面板右上角「–」只切换「大图 ↔ 小圆」，切到小圆时会顺手收起面板。
- 小圆里显示当前心情数字；面板里可以看七项情绪、最近理由、完整时间线和「设置」入口。
- 「心情 → 挂饰」页签有「重置挂饰位置」；表情图在 `vendor/dsh-feiyu-mood/assets/`，替换同名 PNG 即可。
- 挂饰脚本和图片走 `/static/mood-widget.js`、`/mood-assets/*`，不受访问令牌影响；心情数据接口仍需要令牌。

### 5.3 四个页签

**心情**

- 当前表情、数值、七项情绪条、最近理由、时间线。
- 「重置」把心情拉回基线，并记一条「手动重置」事件。
- 「试判断」输入一句「对方说的话」和「你这一轮的回复」，只返回预览，**不写状态**；适合调提示词和阈值。

**会话绑定**

- 槽位模式：
  - `按账号`（默认）：这个账号所有会话共用一份心情；
  - `按会话`：给指定会话单独一份，没绑定的会话回落到默认槽。
- 可以新建、改名、删除槽位；默认槽不能删。
- 会话绑定需要填会话 uid，格式如 `acc_default:wxid_xxx`。uid 可以在「会话」页选中会话后从浏览器开发者工具的元素属性看到，或直接看 `/api/chats` 返回的 `uid`；不绑定也能用账号模式。

**判断与注入**

| 设置 | 默认 | 作用 |
|---|---|---|
| 自动判断 | 开 | 每轮结束是否调用小模型判断；关掉后心情只靠手动重置和衰减 |
| 判断模型 | 空 | 空 = 跟随当前账号模型；也可以填一个模型名（同一服务商） |
| 可信度门槛 | 60 | 判断给出的 confidence 低于它：只记账，不进提示词 |
| 显著阈值（心情） | 3 | `abs(moodDelta)` 达到它才算「显著」 |
| 显著阈值（单项情绪） | 5 | 七项里任意一项涨跌达到它也算「显著」 |
| 注入方式 | 说心情 + 刚才那件事 | `不告诉她` / `只说心情` / `说心情 + 刚才那件事` |
| 每日注入上限 | 6 | 当天最多把心情带进提示词几次（本地 0 点切日） |
| 心情基线 | 70 | 心情自然回落的中心 |
| 心情下限 | 0 | 心情最低值，不能高于基线 |
| 半衰期（小时） | 12 | 心情向基线回落的速度；七项情绪固定 90 分钟半衰 |
| 她叫什么 | 空 | 判断提示词里的自称；空 = 取账号人设名 |
| 对方叫什么 | 空 | 判断提示词里的对方称呼；空 = 取会话名 |
| 别名（逗号分隔） | 空 | 对方平时怎么叫你，避免把「宝宝视频」当成一个东西 |

改完点「保存判断与注入设置」。

**挂饰**

- 重置位置、查看素材替换说明。

### 5.4 它到底怎么动

- **判断**：自动回复发送完成、控制台回合结束后各入队一次；每槽位串行，最多排队 3 轮。判断失败、超时、JSON 非法都只记日志，不影响回复。
- **涨跌**：模型给 `moodDelta`（±10）和七项情绪（各 ±10）。心情实际只吃 `round(moodDelta / 3)`，七项直接加；都钳制在合法范围。
- **显著性**：`|moodDelta| ≥ 3` 或任一情绪 `≥ 5` 才算显著；不显著记一条 `minor`，只进时间线，不进提示词。
- **衰减**：心情向基线半衰（默认 12 小时），七项情绪固定 90 分钟半衰。相差 ≥3 分时记一条「自然平复」事件。
- **注入**：满足「显著 + 可信度够 + 当天额度没用完」才会把心情带进提示词；同一次变化只说一次。
- **隐私**：`说心情 + 刚才那件事` 的具体来历只对**产生它的会话**开放；群聊和其他私聊自动降级为「只说心情」，不带来历。控制台和自然平复不受此限。
- **面板只读**：挂饰每 20 秒刷新一次，只算不写；衰减记录会在下一次判断或注入时真正落库，所以时间线可能比面板数字晚一点出现。

### 5.5 常见现象

- **数值不动**：先看「自动判断」是否开、模型是否配置；判断失败只在日志里，界面不会弹错。
- **时间线有小波动，但 AI 没提**：小波动只记账；或者可信度低、当天额度用完——都是预期。
- **群里不提「刚才那件事」**：故意的，避免把别的会话的私事带进群。
- **挂饰不显示**：确认心情已开启、`/static/mood-widget.js` 能打开、`/mood-assets/face-good.png` 能打开；设了访问令牌时，挂饰数据接口需要浏览器里已有令牌。
- **切账号后心情还是旧的**：页面会自动重载；若没有，刷新一次。

## 6. 主动搭话

搭话让 AI **隔一段时间自己开口**：不看「对方说了什么」，而是按概率挑一个白名单会话发一句自然的开场白。
默认**关闭**，而且**开启后消息是真的会发到微信里**——这是它和其他设置页最大的区别。

### 6.1 开启

1. 先在「搭话」页的**白名单**里加会话（左侧下拉选会话 → 「加入白名单」）。
2. 再勾选右上角「启用主动搭话」，弹窗里确认一次。

没有白名单不能启用（会直接提示）；把白名单最后一条移除，开关会**自动关闭**，避免「开着却没人可发」空转。
所有设置按账号存，切账号页面会自动重载；关掉开关立刻停止调度，不需要重启。

### 6.2 群聊要单独确认

群聊不像私聊那样可以直接加：必须先勾上「我确认允许在群聊里主动开口」，才能把群加进白名单。
群里发出去的话所有成员都能看到，也更容易被当成骚扰，所以这道确认去掉不得。

### 6.3 参数都是什么意思

| 参数 | 默认 | 作用 |
|---|---|---|
| 掷骰间隔 | 30 分钟 | 同一个会话两次掷骰之间的最小间隔；调度器每分钟只看一眼「到时间了没」 |
| 冷却 | 20 分钟 | 上次**主动开口**之后再等这么久才掷；连续手动测试不受它限制 |
| 安静时段（起 / 止） | 1 / 8 | 这段时间完全不掷。**含起不含止**，可以跨午夜（如 23 → 6）；两个值相同表示没有安静时段 |
| 账号每日上限 | 6 | 当天最多自动开口几条，0 = 不限 |
| 单会话每日上限 | 2 | 同一个会话当天最多几条，0 = 不限 |
| 峰时命中线 | 20 | 工作日 09–12、14–18 的基准命中概率（%） |
| 谷时命中线 | 60 | 其余时间（含周末）的基准命中概率（%）——数值越**大**越容易开口 |
| 「刚聊过」窗口 / 系数 | 20 分钟 / 0.15 | 会话刚刚有过消息时，命中线乘上系数，别去插话 |
| 「冷场」阈值 / 系数 | 360 分钟 / 1.5 | 会话很久没动静时，命中线乘上系数，更容易去打招呼 |
| 没掷中加成 / 上限 | 10 / 40 | 每没掷中一次，下一次的命中线加这么多，最多加到上限 |
| 最长字数 | 200 | 开场白超过这个长度会截到这么多字（末尾加省略号）再发；判为「跳过」或空才不发 |
| 触发文案 | 好久没人跟我说话了… | 只告诉 AI「你为什么想开口」，它不会把这句话念出来 |

一句人话：**命中线就是「这一轮该不该开口」的概率门槛**，安静时段之外、间隔和冷却都到了才掷一次骰，
掷中才写开场白、才真发。改完点「保存参数」，下一轮掷骰生效。

### 6.4 三种「试一试」的差别

「试一试」只能选白名单里的会话：

- **试运行（只生成，不发）**：让模型写一句开场白给你看，不发送、不占额度，结果标成「试运行」；
  也不会消耗「这次心情变化只说一次」的心情提示，放心多点几次。
- **真发一条（不占自动额度）**：绕过掷骰直接生成并发送，**会真的发到微信**（点下去前会再确认一次）；
  仍要过闸门（会话是否还允许发、有没有黑名单、通道在不在线），但不吃当天的自动额度，适合验收效果。
- **手动补一条（走闸门、占额度）**：和自动路径一样记账，占今日额度；掷骰一直不中又想测试全流程时用它。

### 6.5 最近记录怎么看

每条记录是一次「事件」，状态含义：

| 状态 | 意思 |
|---|---|
| 已发 | 真的发出去了，同时更新今日已发条数 |
| 没掷中 | 掷骰没过命中线，只留下连败记录（下一次更容易） |
| 跳过 | 掷中了但没发：AI 判断这会儿不该开口（回复了「跳过」），或没过发送闸门 |
| 失败 | 调模型或发送出错，不重试；一条都没发出去时不占额度，部分发出去了按已发的那几条记账 |
| 试运行 | 试运行生成的文本，没发送 |
| 记账异常 | 发出去了但额度/状态记录没写进去，通常是数据库被占用 |

「正在跑」只会出现在「试一试」的结果里（同一会话上一轮还没结束，这次不排队），不会写进这张表。

「每会话状态」表里能看到每个白名单会话今天已发几条、连败了几次、最近一次开口和最近一次掷骰的时间。

### 6.6 为什么开了却一直没发

按这个顺序排查（都是设计里的正常行为，不是坏了）：

1. 通道没连上，或账号驱动不在线；
2. 会话被关掉 AI、处于人工接管暂停、命中黑名单；
3. 会话是内部会话（文件传输助手等），本来就不允许；
4. 现在正处于安静时段；
5. 距上次主动开口还没到冷却或掷骰间隔；
6. 账号或该会话的当日额度用完；
7. 就是**没掷中** —— 默认峰时 20%、谷时 60%，连着几次不掷中很常见，连败会逐次提高下一次的机会；
8. 生成结果被判为「跳过」或空（超长只会截断，不会因此不发）。

只有真的掷过骰、或尝试过发送，才会写进「最近记录」：安静时段、间隔未到、冷却没过、额度用满
这几种「还没轮到掷骰」的情况不写记录，免得每分钟刷一条。所以表里一片空白，通常说明卡在
上面 1–6 条，而不是「掷了没中」。

### 6.7 重启与其他

- **没掷中的次数会保留**：连败计数存在数据库里，重启、换会话、通道断开重连都不会把它清零，
  不会出现「一重启就一直不发」。
- 自动额度按**本地日期**切日，和心情注入同一套口径。
- 发送沿用现有节流（全局间隔、同会话冷却），一次开场白过长会按现有规则拆成最多 3 条。
- 和「主动串门」不是一回事：**串门**是号主在别的会话里说话时，AI 顺着那段上下文插一句；
  **搭话**是没人说话时，AI 隔一段时间自己开口。两者的开关、额度、记录完全独立，互不触发。
- 和「成长」「心情」一样，搭话调模型只在真的掷中之后才发生，掷骰本身不花钱。

## 7. 记忆

- 三层：`core` 长期事实 / `episodic` 某次发生的事 / `session` 会话摘要（默认 7 天过期）。
- 每轮回复按「人物档案 + 核心事实 + 相关往事 + 最近会话」的字符预算注入。
- 「记忆」页可以搜索、置顶、改重要度/置信度/作用域（全局或仅该会话）、手动增改删、导入导出、合并重复。
- 不配 embedding 也能用关键词检索；配了则叠加语义相似度。
- 人物档案是从长期事实和往事里自动汇总的，可手动重算；没有档案时自动退回原始记忆注入。

---

## 8. 成长

- 默认关闭。在「成长」页点「启动成长」才对当前账号生效。
- 基础人设与安全底线固定；口癖、观点、偏好、关系、习惯等会随聊天生长。
- 夜间反思默认 03:30，每账号每天最多一次；关机则下次启动补跑，也可以手动「现在想想」。
- 低风险变化自动生效；立场跳变、身份变化、改号主特质会进「待批」；越界内容直接拒绝。
- 所有变化有时间线和 before/after，可回滚。

## 9. 表情包

- 聊天里出现过的表情会自动收集、自动打标；「表情包」页是按标签筛选的预览墙。
- 可以整库或选中导出 zip（图片 + 标签清单），也可以导入 zip 或一批散图；按内容 md5 去重，同一表情的标签取并集。
- 标签锁保护标签名不被「整理标签」改名/合并；表情锁冻结单张表情的标签、描述、AI 重打标和删除，发送/导出不受影响。
- 库里没有合适表情时，AI 可以联网找图（Bing 优先，斗图啦/发表情兜底），下载入库并自动打标。

## 10. 朋友圈

- 后台会定期从微信本地库同步好友动态与「谁赞/评了我」，默认 10 分钟一轮（`moments.poll_interval`，最低 30 秒）。
- 「立即同步」会先打开微信朋友圈页让客户端拉最新动态，再切回聊天页；期间别动鼠标键盘。
- 点赞、评论也会短暂操作微信窗口；发表朋友圈暂不支持（微信 4.x 限制）。
- 自动回复只读朋友圈文字，不读配图；控制台可以让智能体按 `feed_id` 读某条动态的配图。

## 11. 能力与 B 站

- **技能**：`skills/`、`data/skills/` 下的 `SKILL.md`；系统提示只列名字和描述，模型需要时再读正文。
- **插件**：`plugins/`、`data/plugins/` 下的 `plugin.json`；Python 插件要显式 `trusted: true`，与应用同权限运行，只装可信代码。
- **MCP**：`data/mcp.json`，支持 stdio 与 Streamable HTTP；工具名是 `mcp__服务器__工具`。
- 外部工具默认只在控制台可用；自动回复要同时打开总开关和条目自己的 `auto_reply`。

**B 站（只读）** 在「能力」页底部：

1. 点「安装 / 修复」准备运行环境；
2. 扫码登录；
3. 打开「启用 B 站只读工具」——只注册只读搜索/字幕/评论/热门，发布类工具不注册；
4. 巡逻：填关键词/方向、间隔、每天最多几轮、每轮最多几条、投递方式（控制台/微信/两边）与目标会话；
5. 「现在跑一轮」立即执行；「启用自动巡逻」默认关。

B 站凭证只落 `data/bili/`，不进配置、不进日志，也不会提交到 git。

## 12. 设置页

- **模型**：一档一档的 profile（DeepSeek Flash / MiMo v2.6 Flash / 自定义），每档独立 Base URL、模型名和密钥环境变量；换档立即生效，微信自动回复与控制台一起走。密钥只写 `.env`，`config.json` 不含密钥。
- **人格预设**：切人设、看当前人设；串子模式等开关也在相关区域。
- **自动回复策略**：总开关、群聊需 @、拍一拍、黑白名单、工作时段、间隔、每日上限、接管暂停、前缀、字数上限、跨对话沟通。
- **账号与通道**：新增/编辑/删除账号，选择驱动、填 Hook 或 Webhook 凭据，查看检测到的微信客户端。
- **软件更新**：启动时自动检查（不阻塞），也可以手动检查。侧栏显示 `v1.0.0 · 短哈希`：版本号来自代码里的唯一来源 `app/__init__.py`，短哈希是 `git` 提交号；解压安装（没有 `.git`）的副本只显示版本号，不做在线比对，这不是安装坏了。比对对象由本机 `origin` 推导，Gitee 与 GitHub 都支持，其他主机一律拒绝；分支取「当前分支的上游 → 远端默认分支 → master」，所以在本地分支或 checkout 出来的 tag 上也不会一直报「远端没有这个分支」。私有仓需要本机已缓存的 git 凭据才能读到远端。
- **使用边界**：能力与风险说明。

## 14. 常见问题

**微信完全不回**
先看「概览」通道是否已连接；再看「设置 → 自动回复策略」总开关、会话 AI 开关、是否被人工接管、黑白名单/工作时段/每日上限；最后确认模型 Key 与「测试连接」。群聊记得 `@昵称`。

**微信 4.x 发送时窗口被顶到前台**
这是 weixin4 通道的发送方式：搜索会话 → 粘贴 → 回车，结束会把原来的前台窗口还回去。启动项目后如果觉得微信「单击发飘」，先跑一次 `.venv\Scripts\python.exe tools\wx_click_watch.py 120` 留证，再判断是输入被抢还是消息循环卡住。

**朋友圈一直不同步**
看 `moments.enabled` 与 `poll_interval`；默认 10 分钟一轮。点「立即同步」会短暂操作微信窗口，期间别动键鼠。

**心情数值变了但 AI 没提**
小波动、可信度低于门槛、当天额度用完，都只记账不注入。想更常说，降低可信度门槛或提高每日上限；想更少说，反过来。

**开了搭话为什么一直没发**
先看「搭话」页右上角的调度状态是否「调度中」，再看「最近记录」：一条记录都没有 = 调度没跑或会话不在白名单；
只有「没掷中」= 概率没到，正常，等或者把峰/谷命中线调高；有「跳过」= 生成结果被判不该发或没过闸门（会话关了 AI、
被接管、命中黑名单、当日额度用完、正在安静时段）；有「失败」= 看那一行的错误。想立刻验证效果，用「试运行」看文本，
再用「真发一条」实测。

**挂饰/图片 404**
确认 `vendor/dsh-feiyu-mood/assets/` 六个 PNG 存在；挂饰脚本是 `/static/mood-widget.js`，图片是 `/mood-assets/*`。设了访问令牌时，`/api/mood/state` 需要令牌，静态资源不需要。

**控制台打不开 / 一直要令牌**
默认地址 `127.0.0.1:8765`；若改过端口看 `data/config.json` 的 `server.port`。令牌在 `server.access_token`，输入后存在浏览器 `localStorage`；换浏览器要重新输入。

**数据会不会上传**
默认只连你配置的模型服务；B 站、微信、记忆都在本机。只有你主动开联网找表情、B 站工具或 MCP 时才会访问对应外部服务。AI 联网抓取会拒绝本机与内网地址，重定向的每一跳都重新校验一遍，不会被一条 302 拐回 `127.0.0.1` 去读你的聊天。

## 15. 风险与边界

- 微信自动化有风控风险：发送节流、拟人节奏、每日上限都是为此准备的；被踢过之后请调大间隔养号。
- 不要把小号、客户号直接交给自动回复；先用测试会话跑通策略。
- **发送受身份闸门保护**：每次发送前会确认通道实际绑定的微信身份。身份确认不了（通道没正常启动）就只收不发；把某个 wxid 填进 `send.forbidden_wxids` 后，该账号一律拒绝发送，控制台会写明原因。要永久禁止某个号发言（例如你自己在用的主号），把它的 wxid 写进本地 `data/config.json`——这个文件不进 git。
- **微信 4.x 的账号目录配错时不会自动改绑**：目录不存在（微信升级、迁移、被 OneDrive 重定向都会导致）通道直接报错停止，等你在控制台重新选择。以前它会自己挑一个「有可见窗口的账号」继续跑，那有把消息发到别的号上去的风险。
- **写操作只允许本机**：改配置、发消息、重启服务这类非只读请求，来源必须是回环地址。**未设访问令牌时，`/api/*` 也只接受本机来源**，把 `server.host` 改成 `0.0.0.0` 不会让外部直接读到聊天与配置；浏览器跨站写请求还会按 `Origin` 拒绝。启动时若没设访问令牌、或监听了非本机地址，控制台进程会打印提示与警告。实时推送通道（`/ws`，会把聊天内容持续推给连接方）始终只允许本机，设了访问令牌时还要带令牌，控制台会自动带上。
- **AI 发文件限定在本程序目录**：`send_wechat_file` 只能发送 `data/downloads`（联网下载落点）与 `data/agent_uploads`（控制台上传落点）里的文件，其它路径直接拒绝——否则一句诱导就能把 `.env` 或 `data/agent.db` 发给任意联系人。控制台里人工选文件不受此限。
- **重名会话不会猜着发**：AI 指定的收件人如果按名字模糊匹配到多个会话，会被拒绝并列出候选，需要给完整显示名或会话 ID；完全同名的匹配仍然照常命中。
- **凭据只显示后 4 位**：设置页里的访问令牌、webhook 凭据、MCP 配置的 `Authorization` 都只回显 `••••••••` 加后 4 位；直接保存不会把脱敏串写成真值，想清空就把字段改成空。模型 API Key 仍只存 `.env`，不进 `config.json`。
- 插件与 Python 插件、MCP 服务器都拥有你给它的权限，只接可信来源。
- 本项目不做：微信支付、小程序、语音/视频通话。微信 4.x 由内置的 `weixin4` 通道支持（后台解密收消息 + UIA 前台发送），不需要通用 Hook；4.x 的发送会把微信短暂顶到前台。
