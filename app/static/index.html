            模型配置
            

            点一档即用这一档；地址、模型名与 API Key 都跟着这一档走
          

          

            
            
            
            
          

          

            
识图（图片输入）当前模型需支持 OpenAI 图片消息格式；关闭时图片只显示占位

            
          

          

            
联网能力（搜索 / 抓取 / 下载）开启后智能体可搜索网页、读取正文、下载文件到 data/downloads

            
          

          

            
长期记忆聊天后自动提取值得记住的事，下次对话按相关度带上；每个账号的记忆相互独立

            
          

          

            
人物档案从长期事实和往事里自动汇总关系、偏好、雷区、最近话题；关掉后只注入原始记忆

            
          

          

            
            
            
          

          

            
语义检索（embedding）可选：配置 OpenAI 兼容的 /embeddings 接口，按语义相似度召回；不配也能用关键词检索。密钥放 .env 的 EMBEDDING_API_KEY（或下面自定义变量名）

            
          

          

            
            
            
          

          

            
回复必带表情包每次自动回复至少配一个表情包，AI 按场景从表情库自选；模型忘带时自动补发一个

            
          

          

            
添加聊天中的表情包聊天里出现的表情包自动收进表情库（对方发的、自己发的、群聊和合并转发里的都算）；关闭后不再自动收集，手动收藏和导入不受影响

            
          

          

            
仅 AI 娘表情包维护 AI 娘世界观：只允许发送 tags 里带图鉴角色名（大肥鱼、小肥鱼、Claude娘 等）的表情，杂梗图自动被过滤；与串子模式同开时，串子站入库的表情优先，且不受角色名标签限制。

            
          

          

            
串子模式回复像串子：默认每轮找机会串，会高级黑（捧杀/假中立/拉踩/阴阳怪气），只对准观点/梗，不对准人。正经/情绪/隐私/金钱场景收梗，只配安慰/倾听/正经向的图，不发串子图。可与「仅 AI 娘表情包」同开，库内「串子站」图优先且不受角色名限制。秒回时正文先发，台词不参与正文；开着「回复必带表情包」时文字后自动补图，关闭时可按需发图。

            
          

          

            
串子站表情包串子模式下允许 AI 联网查 searchanythingfun 台词库并入库截图（每轮最多 1 次、只入库 1 张；配额不足或 429 自动回落本地）。默认关闭：不联网查站、不新增站内图，已入库的「串子站」表情照常检索和发送。

            
          

          

            
跨对话沟通允许 AI 给当前会话以外的人发消息：好友要求带话/转告时真的发到指定的人，也能在你和其他人聊天时插一句话。默认开启，发现异常先关掉

            
          

          

            
允许转告 / 代发聊天里被明确点名收件人时，AI 可以代你把消息发到对方指定的微信联系人/群，并在当前会话回一句确认

            
          

          

            
允许主动串门号主本人在其他会话聊天时，AI 可以自主决定去那个会话补一句话；同一会话有冷却，会话处于人工接管暂停时不会串门（把设置里的暂停设为 0 才能随聊随串）

—

使用边界

          
    
            
  • 账号风险：个人微信自动化不符合《微信个人账号使用规范》，存在被限制或封禁的可能，建议用小号先验证。
    • 
            
  • 版本限制：本地 Hook 仅支持微信 PC 3.9.x；4.x 收消息走数据库解密，发送走前台窗口自动化（会短暂占用前台）。
    • 
            
  • 能力边界：朋友圈、支付、小程序、语音视频通话不在 Hook 能力范围内。
    • 
            
  • 数据：所有消息与配置只存在本机 data/ 目录，不同账号的数据按账号隔离。
    • 
            
  • 协议：使用本软件即表示同意本项目的；英文译本仅供参考，以中文版为准。
